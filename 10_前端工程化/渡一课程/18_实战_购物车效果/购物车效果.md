# 需求实现思路
UI界面类(UI) 包裹 UI数据类(UIData) 包裹 UI商品类(UIGoods)

## 思考数据逻辑
```
class UIData {
    // 获取全部商品总价
    getTotalPrice() 
    // 根据index增加某件商品的选中数量
    increase(index)
    // 根据index减少某件商品的选中数量
    decrease(index)
    // 获取总共选择中商品数量
    getTotalChooseNumber()
    // 购物车中是否有商品
    hasGoodsInCar() 
    // 是否跨越了配送门槛
    hasCrossDeliveryThreshold() 
    // 获取配送费用+商品总价
    getTotalMoney()
    // 根据下标index判断是否选中了此件商品
    isChoose(index)
}
```

## 思考界面逻辑
```
class UI {
    // 根据商品数据创建商品列表元素
    createHTML()  
    // 根据index增加某件商品的选中数量,并更新页面逻辑
    increase(index)
    // 根据index减少某件商品的选中数量,并更新页面逻辑
    decrease(index) 
    // 更新商品信息
    updateGoodsItem(index)
    // 更新页脚详细信息
    updateFooter()
    // 注册监听事件
    listenEvent() 
    // 购物车缩放动画
    carAnimate()
    // 抛物线跳跃元素
    jump(index)
}
```
