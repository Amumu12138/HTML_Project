### 得到属性描述符
```
Object.getOwnPropertyDescriptor(obj, 'a')
```

### 设置属性描述符
```
Object.defineProperty(obj, 'a', {
    value: '', // 值
    writable: true, // 是否可重写
    enumerable: true, // 是否可遍历
    configurable: true // 属性描述符能否再次配置
})
```
