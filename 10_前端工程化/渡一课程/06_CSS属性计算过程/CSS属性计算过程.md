### 属性值的计算过程
![属性值的计算过程](../截图//CSS属性计算过程/CSS属性值计算过程.png)

1、确定声明值: 找到没有冲突的样式,直接作为计算后的样式
2、层叠: 
a、比较重要性(从高到低)
    1) 带有important的作者样式
    2) 带有important的默认样式
    3) 作者样式
    4) 默认样式
b、比较特殊性
对每个样式分别计数
style: 内联-1 非内联-0
id: id选择器的数量
属性: 属性、类、伪类的数量
元素: 元素、伪元素的数量
c、比较源次序
源码中靠后的覆盖靠前的
3、继承
对仍然没有值的属性,若可以继承(一般为文字相关属性),则使用继承
inherit: 继承父级,直接使用父级的属性值
4、使用默认值
对仍然没有值的属性,使用默认值
initial: 属性默认值
unset: 在确定声明值和层叠步骤时,没有设置属性值
all: unset; // 清除浏览器全部属性默认值
示例:
// 清除浏览器默认样式
body, body *:not(script) {
    all: unset;
}
all: revert; // 回归浏览器默认值
示例
.default {
    all: revert;
}
