# html_project

## 一、文件目录
``` 
    .vscode                --- vscode配置文件
    01-WebStudy-master     --- 大佬编程学习目录
    02-html                --- html超文本学习文件
    03-css                 --- css样式学习文件
    04-javaScript          --- js学习教程
    05-typeScript          --- ts教程学习
    06-vue                 --- vue 学习项目
    07-react               --- react 学习项目
    08-webgl               --- webgl 教程学习
    09-threeJs             --- three.js 3d引擎项目
    10-泡椒思志项目          --- 泡椒思志项目
    README.md              --- 项目介绍
```
## 二、详情介绍
```
    threeJs目录下入口文件都为index.html,引入第三方库文件为js,案例文件为example,example/client目录下文件为《WebGL编程指南》部分示例文件

    vue目录下包含vue2.x和vue3.0相关学习项目

    react目录下包含react、react-router、redux相关学习项目

    webgl目录下入口文件为index.html,res目录为资源目录,案例文件为example,shader.html为标签化添加着色器语言示例

    javaScript目录文件入口为index.html,JavaScript是Web的编程语言,所有现代的HTML页面都使用JavaScript. 
    案例文件为example,css存放为样式文件,images存放为项目所用到的图片/动画文件
```
