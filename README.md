# html_project

## 一、文件目录
``` 
    infox_h5_sdk        --- 银狐H5项目
    javaScript          --- js学习教程
    matter              --- matter.js物理引擎项目
    platfrom-web-sdk3-h5-engine --- 基于泡椒-h5-sdk2.0的更新版本项目
    platfrom-web-sdk3-h5-engine-copy --- 基于泡椒-h5-sdk2.0的IDEA项目
    test                --- 练手实操文件
    threeJs             --- three.js 3d引擎项目
    typeScript          --- ts教程学习
    vue                 --- vue 学习项目
    webgl               --- webgl 教程学习
    helloWorld.html     --- html测试案例
    index.html          --- 新增HTML文件入口
    README.md           --- 项目介绍
```
## 二、详情介绍
```
    matter和threeJs目录下入口文件都为index.html,引入第三方库文件为js,案例文件为example,example/client目录下文件为《WebGL编程指南》部分示例文件
    vue目录下入口文件为index.html
    webgl目录下入口文件为index.html,res目录为资源目录,案例文件为example,shader.html为标签化添加着色器语言示例
    javaScript目录文件入口为index.html,JavaScript是Web的编程语言,所有现代的HTML页面都使用JavaScript. 
    案例文件为example,css存放为样式文件,images存放为项目所用到的图片/动画文件
    platfrom-web-sdk3-h5-engine目录入口文件/demo/h5/index.html,css目录为引入样式库,js为引入js文件库,node_m
    odules为npm引入的第三方库,整个项目是基于泡椒-h5-sdk2.0的更新版本
    infox_h5_sdk目录入口文件/WebRoot/demo/h5/game.html, 整个项目是基于银狐H5项目的开发
```
