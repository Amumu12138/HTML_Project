# HTMLProject

这是一个用于前端学习、代码练习和项目实践的综合仓库，覆盖了前端开发中常见的基础知识、进阶技术和实际项目实践。仓库中的内容主要用于个人学习、案例演示、实验记录以及面试准备。

## 一、项目定位

该仓库按前端学习阶段进行整理，内容包含：

- HTML / CSS 基础与布局
- JavaScript 基础与高级特性
- TypeScript 语法与工程化应用
- Vue 与 React 前端框架学习
- WebGL 与 Three.js 3D 图形开发
- Vite、Node.js 等工程化与后端基础
- 面试题与简历资料整理

整体结构清晰，适合从入门到进阶逐步学习，也便于后续扩展新项目与技术点。

## 三、各模块详细介绍

### 1. 01-WebStudy-master
这是一个较完整的前端学习资源目录，通常包含：

- HTML/CSS 基础知识
- 常见布局案例
- 导航栏、页面结构、响应式布局等实例
- 部分项目式学习内容

适合用来巩固基础知识和理解常见前端布局思路。

### 2. 02-html
用于学习 HTML 结构与语义化标签，包含：

- 基础标签使用
- 表单与多媒体内容
- 页面结构设计
- HTML 练习案例

### 3. 03-css
用于学习 CSS 样式设计，常见内容包括：

- 盒模型、浮动、定位
- Flex / Grid 布局
- 动画、过渡、伪元素
- 常见页面效果和样式工程化

### 4. 04-javascript
这是项目中最核心的模块之一，通常包含：

- JavaScript 基础语法
- 条件判断、循环、函数、数组、对象
- DOM 操作与事件处理
- ES6+ 新特性
- 高阶函数、闭包、原型链等
- 算法、设计模式、项目案例

该目录是前端学习的重心，适合反复练习和回顾。

### 5. 05-typeScript
TypeScript 相关内容，适合学习：

- 类型系统
- 接口、泛型、枚举
- 模块化开发
- 强类型工程化开发思路

### 6. 06-vue
该目录用于 Vue 相关学习，包含：

- Vue 基础语法
- 组件化开发
- Vue Router、状态管理等
- Vue 2 / Vue 3 相关项目与案例

### 7. 07-react
React 目录主要用于学习：

- React 组件开发
- JSX 与状态管理
- React Router
- Redux / MobX 等状态方案
- 前端工程化示例

### 8. 08-webgl
WebGL 学习目录，通常包含：

- 着色器基础
- 图形绘制
- WebGL 原生案例
- 资源目录与示例文件

### 9. 09-threeJs
Three.js 3D 引擎学习目录，通常包括：

- 场景、相机、光照、几何体
- 3D 动画
- 资源目录和示例源码
- index.html 入口页面

### 10. 10_前端工程化
用于学习前端工程化思想，常见内容包括：

- 构建工具
- 模块化
- 代码规范
- 组件化工程实践
- 课程学习资料（如渡一课程等）

### 11. 100_前端面试
主要用于面试准备，内容包括：

- 面试题整理
- 笔试题记录
- 简历模板
- 面试经验与复盘

### 12. 11-vite
Vite 工具学习目录，通常用于：

- Vite 项目初始化
- 资源处理
- 前端脚手架使用
- 前端开发环境配置

### 13. 12-nodejs
Node.js 学习目录，适合了解：

- Node.js 基础
- Web 服务
- 文件操作
- 模块化与后端基础知识

### 14. 99-泡椒思志项目
此目录用于项目实践与业务相关学习，通常包括：

- SDK / 平台相关内容
- 实际业务案例
- 项目经验积累

## 四、推荐学习路线

建议按下面顺序学习：

1. HTML + CSS：先打牢基础，重点看 01-WebStudy-master、02-html、03-css
2. JavaScript：掌握语法与 DOM 操作，重点看 04-javascript
3. TypeScript：学习强类型开发思维，进入 05-typeScript
4. 前端框架：Vue / React 学习，重点看 06-vue、07-react
5. 高级能力：WebGL / Three.js，重点看 08-webgl、09-threeJs
6. 工程化与后端：10_前端工程化、11-vite、12-nodejs
7. 面试准备：100_前端面试
8. 项目实践：99-泡椒思志项目

## 五、使用建议

- 先从基础目录开始，避免跳过基础语法
- 代码文件可直接本地打开浏览器预览，部分案例需依赖本地环境
- 结合目录中的 example、demo、resources 等文件夹理解实际应用
- 对重点案例及时做笔记，方便后期复盘和回顾

## 六、总结

这个仓库覆盖了前端学习中的大部分常见路径，适合构建系统性学习资料库。无论是基础知识巩固，还是框架学习、3D 图形、工程化实践、面试复习，都可以在这里找到相应内容。

如果需要进一步整理，可以继续把各个目录补充成更细的 README、学习笔记和任务清单，使其更适合作为正式学习文档使用。
